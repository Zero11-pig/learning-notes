# Painterly Animation Style (Kok Boru 风格)

基于 Higgsfield《Kök Börü》（苍狼）开源提示词体系提炼的通用生图风格框架。
适用于任何生图模型：即梦、Midjourney、Stable Diffusion、Flux、DALL-E 等。

---

## 核心原理（基于原片开源 Style Prefix + Constraints）

Kok Boru 风格 ≠ 三渲二 ≠ 赛璐璐。它的真实定义来自官方开源的两大体系：

### Style Prefix（风格前缀）— 定义"画面是什么"
1. **定格动画美学** — 逐帧跳跃式动作，手绘2D动态油画质感
2. **非粘土、非木偶、非3D** — 手绘油画+哑光水粉笔触
3. **逐帧手绘** — 12fps on-twos，笔触和轮廓逐帧微妙变化（painterly BOIL）
4. **笔触即表演** — 笔触有温度，厚重可见，边缘柔和
5. **无平滑插值** — 无动态模糊、无形态渐变、无液体表面变形

### Constraints（约束条件）— 定义"画面不能是什么"
1. **非照片级写实，非3D，无光泽感**
2. **80%阴影 + 20%光照** — 低调照明，阴影柔和丰富非死黑
3. **光线柔和漫射** — 无刺眼光束、无神光（god rays）、无体积光
4. **面部清晰可见** — 即使在暗部，五官也绝非漆黑一片
5. **中性白平衡微冷** — 非蓝色滤镜，非电光蓝夜景
6. **低饱和暖土暗调** — 色彩柔和，饱和度低，大地色调
7. **变形宽银幕镜头** — anamorphic lens，浅景深柔和如绘画渐变

## 固定锚点词详解

| 锚点词 | 作用 | 为什么不能改 |
|--------|------|-------------|
| `Stop-motion animation` | 锁定格动画美学 | 原片开源 Style Prefix 首词 |
| `hand-drawn 2D oil painting texture` | 锁定手绘油画质感 | 区别于3D/粘土/木偶 |
| `painterly style` | 锁定画意风格 | 防止矢量平涂/赛璐璐 |
| `12fps on-twos` | 隔帧动画节奏 | 还原手绘动画节奏感 |
| `painterly BOIL` | 笔触逐帧抖动 | 逐帧手绘的标志特征 |

| `80%阴影20%受光` | 低调照明比例 | 原片开源 Constraints 核心数值 |

| `anamorphic` | 变形宽银幕镜头 | 原片使用的镜头类型 |

## 🎬 景别适配系统（核心：任何景别风格不变）

原片开源资料显示：不同景别使用不同焦距镜头，但 Style Prefix 和 Constraints 始终不变。以下系统确保从远景到特写，画风100%一致。

### 景别适配原则

**不变的（所有景别共用）：**
- Layer 1 风格锚点 — 完全相同
- Layer 3+4 光影约束 — 完全相同
- Layer 5 负面词 — 完全相同
- 80/20 明暗比 — 完全相同
- 低饱和暖土暗调 — 完全相同
- painterly BOIL 笔触感 — 完全相同

**随景别变化的（只在 Layer 2 内调整）：**
- 焦距（35mm / 50mm / 85mm）
- 构图描述
- 景深程度
- 人物在画面中的占比

### 五大景别模板

#### 1. 超广角远景（Extreme Long Shot）
```
超广角远景，约35mm变形宽银幕镜头，人物渺小如点，环境占据画面主体。三分法构图，地平线低。大与小的对比，自然环境压倒人物。大气运动（云、雾、草浪）流畅，人物为静态剪影点缀。明暗对比强烈，明亮的蒙古包/营地与巨大的暗色山峦形成对比。
```

#### 2. 全景（Full Shot / Long Shot）
```
全景，约35mm变形宽银幕镜头，人物全身可见，与环境并重。三分法构图，人物置于交叉点。人物动作清晰但渺小感保留，环境氛围浓厚。大气运动流畅，人物以隔帧节奏活动。明暗对比：人物受光区域与背景阴影形成层次。
```

#### 3. 中景（Medium Shot / Medium Long Shot）
```
中景，约35-50mm变形宽银幕镜头，人物腰部以上可见。三分法构图，人物偏离中心。双人对话时一人在左下三分之一、一人在右三分之一。面部表情开始可见，但保持克制。柔和阴影笼罩大部分画面，面部略带柔光。布料、毛发有次要动作。
```

#### 4. 中近景（Medium Close-Up）
```
中近景，约50mm标准镜头，人物胸部以上。真实自然的肖像透视，无畸变。面部表情清晰可见，微表情克制传递情感。三分法构图，面部置于画面三分之一处。目光方向引导视线。浅景深柔和，背景如绘画般渐变虚化，非强烈散景。约80%阴影，面部略带柔光。
```

#### 5. 特写（Close-Up）
```
特写，约85mm人像镜头，轻微压缩感。面部/双手/物件占据画面主体。极浅景深柔和细腻，背景如绘画般柔和渐变，绝非强烈摄影散景。微表情、呼吸、眨眼清晰可见但克制。单一柔和光源，面部受光区域约占20%，柔和阴影占80%。细节丰富但笔触概括，非照片级纹理。焦点物件（项链/手/眼睛）是视觉核心。
```

### 景别 × 焦距 × 景深速查

| 景别 | 焦距 | 景深 | 人物占比 | 面部可见度 | 叙事用途 |
|------|------|------|---------|-----------|---------|
| 超广角远景 | 35mm | 深 | 极小（点） | 不可见 | 环境、孤独、宏大 |
| 全景 | 35mm | 深 | 全身 | 模糊 | 动作、环境关系 |
| 中景 | 35-50mm | 中等 | 腰部以上 | 表情初现 | 对话、互动 |
| 中近景 | 50mm | 浅 | 胸部以上 | 清晰可见 | 肖像、情绪 |
| 特写 | 85mm | 极浅 | 面部/局部 | 微表情可见 | 内心、细节 |

### 景别组合示例（模拟原片镜头切换）

原片常用**硬切**在四个镜头间切换，每个景别不同但风格统一：

```
镜头1：中景双人镜头（35mm）— 全景关系，两人距离感
  → 硬切
镜头2：中近景（50mm）— 聚焦说话者面部表情
  → 硬切
镜头3：特写（85mm浅景深）— 聚焦手部动作/物件
  → 硬切
镜头4：面部特写（85mm人像）— 聚焦眼神和微表情
```

**关键：四个镜头风格完全一致**，因为 Layer 1 + Layer 3/4 + Layer 5 一字不改，只有 Layer 2 中的焦距和构图变化。

## 🔒 风格锁定系统 (Style Lock)

### 核心原则：三不变 + 三锁定

**三不变（每张图必须100%一致）：**
1. **锚点词不变** — Layer 1 的 6 个英文锚点词原封不动
2. **光影约束不变** — Layer 3+4 的明度范围、色温、饱和度参数原封不动
3. **负面词不变** — Layer 5 的负面清单原封不动

**三锁定（在 Layer 2 主体描述中固定）：**
1. **色温锁定** — 固定暖光色温值 + 冷影色温值
2. **明度区间锁定** — 固定 `明度10%-55%` 数值范围
3. **笔触密度锁定** — 固定 `6-7大色块` + `thick visible brushstrokes`

每次生成前，逐项核对：

```
□ 非照片级写实非3D无光泽感 ✓

□ Layer 2 中是否有 thick visible brushstrokes？
□ 画面是否有明确暗部大面积(80%)+亮部极小(20%)？
□ 是否避免了纯白纯黑（用深灰替代）？
□ 是否避免了光泽感/塑料感？
```

### 跨图一致性验证法

生成系列图时，将第一张满意的作品作为"基准图"，后续每张对比验证：

| 验证维度 | 基准图特征 | 后续图须匹配 |
|---------|-----------|-------------|
| 笔触质感 | 厚重油画笔触可见 | 笔触粗细、密度一致 |
| 明度范围 | 暗→亮的过渡区间 | 明度分布曲线一致 |
| 色温倾向 | 暖光区+冷影区 | 色温偏移量一致 |
| 饱和度 | 低饱和 muted | 饱和度数值接近 |
| 边缘处理 | 柔和无硬边 | 边缘柔化程度一致 |
| 色块数量 | 6-7大色块概括 | 色块分层数量一致 |

### 系列图生成流程（推荐工作流）

```
Step 1: 生成基准图
  → 选定人物/场景模板
  → 组装完整提示词
  → 生成 → 挑选最满意的一张作为"基准图"

Step 2: 后续每张图
  → 复制基准图的完整 Layer 1 + Layer 3/4 + Layer 5（一字不改）
  → 只替换 Layer 2 主体描述
  → 如有参考图功能：上传基准图作为风格参考
  → 如有 seed 功能：固定基准图 seed

Step 3: 生成后对比验证
  → 对照"跨图一致性验证表"逐项检查
  → 如偏差：加强锚点词权重 ((Hand-drawn 2D animation))
  → 如色彩偏移：在 Layer 2 末尾追加色板锁定词
```

## 不同模型适配建议

### 即梦 (Dreamina)
- 正向提示词控制在 400-500 字符内
- 负面提示词单独填入负面框
- 风格锚点词放在最前面
- 中文+英文混合输入效果更好
- 如仍偏写实：给锚点词加权 `((Hand-drawn 2D animation))`

### Midjourney
- 使用 `--style raw` 参数关闭美化倾向
- 加 `--stylize 200` 降低风格化
- 模板中的中文可删除，保留英文锚点即可
- 加 `--ar 4:3` 或 `--ar 16:9`

### Stable Diffusion / Flux
- 负面提示词填入 negative prompt 框
- CFG scale 建议调低至 4-6（过高会过度锐化）
- 采样步数 25-35 即可

### DALL-E 3
- DALL-E 无负面提示词，将负面约束转为正向否定句
- 例如："非写实，非3D，非CGI"

## 常见问题排查

| 生成结果 | 原因 | 解决方法 |
|---------|------|---------|
| 太写实 | 锚点词权重不够 | 给 `Hand-drawn 2D` 加权 `((Hand-drawn 2D))` |
| 变成日漫风 | 模型倾向 anime | 负面框加 `anime, cel shading, 赛璐璐` |
| 笔触不明显 | 模型过度平滑 | 正向加 `thick visible brushstrokes` |
| 太亮 | 光影约束没生效 | 把 `暗调沉稳` 放到最前面 |
| 色彩太艳 | 饱和度太高 | 正向加 `muted desaturated palette` |
| 有3D感 | 锚点被覆盖 | 负面加 `3D render, CGI, Octane render` |
| 油光满面 | 高光过多 | 负面加 `oily skin, excessive highlight` |
| 生成失败 | 字数超限 | 正向控制在 500 字符内，负面控制在 300 字符内 |
| 人物肤色不对 | 肤色锚点被覆盖 | 把肤色词放在面部描述最前面 |
| 场景太空 | 缺少细节 | 加人物剪影或动物点缀 |
| 海面太蓝太亮 | 色彩过饱和 | 加 `深蓝灰, muted blue` 替代 `蓝色` |
| 海面变写实水面 | 模型倾向写实反射 | 正向加 `painterly water, flat color blocks`，负面加 `realistic water reflection` |
| 文化服饰不准确 | 模型知识不足 | 在服饰描述中增加具体材质词和颜色词 |
| 多人物混乱 | 主体太多 | 减至1-2人，加 `焦点居中` |
| 系列图风格漂移 | 锚点词被截断 | 每次重新完整粘贴 Layer 1，使用参考图 |
| 海战场景太暴力 | 触发审核 | 改为远景剪影，去掉直接战斗描写 |
| 极地场景太白 | 明度超标 | 强调 `暗调沉稳, 明度10%-55%`，加 `dark snow` |
| 水下场景太暗 | 明度太低 | 适当提高至 `明度15%-50%`，加 `underwater light rays` |
| 人物+场景太挤 | 信息过载 | 人物简化为剪影，突出场景 |

### 风格不变性验证（自检3问）

生成任何图后，问自己：
1. **笔触可见吗？** — 如果表面平滑无笔触 → 锚点权重不够
2. **暗部占80%吗？** — 如果画面太亮 → 光影约束没生效
3. **像油画不像照片吗？** — 如果有写实皮肤/光泽 → 负面词不完整

三问全"是" → 风格正确。任一"否" → 按风格漂移修复指南调整。

## 风格来源

基于 Higgsfield《Kök Börü》（苍狼）官方开源提示词体系提炼。
原片为 AI + 手绘混合制作的二维动画短片，改编自哈萨克民间传说。

**开源两大体系：**
- **Style Prefix（风格前缀）**：定义定格动画、手绘2D油画质感、12fps on-twos、painterly BOIL、非粘土非木偶非3D
- **Constraints（约束条件）**：定义80%阴影/20%光照、柔和漫射无神光、中性白平衡微冷、低饱和暖土暗调、变形宽银幕镜头、浅景深如绘画渐变

**原片技术要点：**
- 不同景别使用不同焦距：35mm广角远景、50mm中近景肖像、85mm特写浅景深
- 项目先制作"风格基调图"贯穿全片，所有素材参考该图生成
- 每个镜头有独立文件夹，保存多个版本以便筛选
- AI生成初稿 + 艺术家Photoshop修改 + 局部调整的工作流
- 对文化真实性要求高：服饰纹样、皮毛质感、游牧环境需艺术家校准
