# 电影感视频提示词生成器（Cinematic Scene Prompt Generator）

## 触发条件

当用户提供以下任意一种输入时调用本 Skill：
- 一张或多张参考图片 + "帮我写提示词"
- 一段关于视频场景、人物、转场、氛围、摄影风格、声音设计的口头描述
- 明确要求"王家卫""诺兰""IMAX""胶片""概念艺术""机甲""色卡""手持""音效""分镜"等关键词
- 需要把图片内容转化为可供 AI 视频工具（如 Seedance / Midjourney Video / Sora / Runway / 可灵 / 即梦等）使用的结构化中文提示词

## 核心能力

本 Skill 把用户提供的视觉参考和创意意图，转化为一份**可直接用于 AIGC 视频生成的高度结构化中文提示词**。强调：

1. **秒级时间轴**：把视频按 0–N 秒拆分，每一秒都有明确动作、机位、焦点、转场
2. **导演/摄影/技术规格**：导演、摄影指导、胶片/数字格式、手持、景深、光圈、f-stop、**焦距/焦段**、画幅
3. **电影转场技巧**：rack focus、前景遮挡擦镜变装、动作匹配硬切、车辆/电车擦镜、弧线环绕拉远 reveal、黑屏定格
4. **微观→宏观 reveal**：从局部特写/小道具开始，通过镜头运动逐步揭示宏大场景或巨型物体
5. **道具驱动镜头**：小物件（票、符纸、信件、罗盘、手机等）作为视觉锚点，牵引镜头运动和叙事节奏
6. **色卡锁定、色彩执行与 Swatch Sheet 生成**：严格按 HEX 色值分配画面元素，标注视觉异色点；可生成电影调色用的 Swatch Sheet，严格定义版式、HEX 值、标签和约束
7. **空间关系精确描述**：机位、朝向、前景/中景/背景、可见边界、人物与巨型物体的尺度关系
8. **音效与声音设计**：环境底噪、动作音、标志性转场音、情绪声音曲线、作曲家/风格参考
9. **台词/对白**：音色、语气、语言、情绪状态、口型匹配要求
10. **视觉风格定调**：胶片颗粒、导演色调、低饱和暖调、浅景深、变形宽银幕、厚涂概念艺术、中国传统奇幻/机甲色彩等
11. **平台输出参数与否定约束**：分辨率、时长、画幅、无字幕、无水印、无 BGM 等
12. **人物一致性约束**：五官、发型、身高比例、服装颜色在换装/转场/多角度中保持不变
13. **镜头角度与构图系统**：高低视角、人物朝向、特殊视角、景别、构图、光影、氛围、主题等实战七要素
14. **焦距与镜头焦段选择**：根据焦距数值控制视角宽窄、空间压缩感、主体大小与场景氛围
15. **极端光影与选择性照明**：只有被特定光源打到的部分可见，其余沉入纯黑；用 rim light 勾勒人物边缘，制造高对比剪影
16. **方向性能量/粒子流动**：光线、雾气、碎屑等沿明确方向运动（如从门内涌向人物），并明确禁止反向
17. **环境力的视觉证据链**：通过头发飞舞、物体摇晃、碎屑飞舞、衣料鼓动等细节可视化风压/能量场
18. **复合镜头运动与同步变换**：orbit 环绕 + 荷兰角同步倾斜/恢复、焦点转移与固定机位结合等
19. **巨型物体逼近与黑屏收束**：从远景门/洞中出现→越过前景→加速放大→覆盖画面→五指合拢/抓取→abrupt cut to black
20. **声音设计的阶段化推进**：wind tunnel → drone 升高 → energy crackle → BRAAAM crescendo → abrupt silence
21. **色卡作为整段画面色板锚定**：明确声明色卡是整段画面的色彩锚点，所有元素严格按 HEX 执行
22. **高速光线/粒子网络**：密集光线形成网络，粒子沿光线高速流动，如电流在血管中奔涌
23. **视觉异色点强化**：在统一色温中刻意安排小面积对比色，并明确其色相、位置、面积与叙事功能
24. **道具色彩微差控制**：核心道具与服装/背景保持同一色调但存在可辨识色差，避免融为一体的同时不破坏整体色板
25. **冲击波纹与尘埃轨迹**：将能量爆发可视化为中心向外扩散的同心圆冲击波纹，以及被强风推动的尘埃粒子运动轨迹
26. **声音对比设计**：在统一低频/暖调声场中刻意安排瞬间出现的异色声音（如电子拨号音、冷色屏幕音），形成听觉视觉同步对比
27. **罗盘/手机类精密道具刻画**：对罗盘刻度、指针、材质反光、手机屏幕冷光、拨号 UI 等细节进行精确描述，使其成为叙事锚点

## 硬性时长约束

- **所有视频提示词时长不得超过 15 秒**。无论用户要求 20 秒、30 秒还是 1 分钟，输出时必须统一压缩到 ≤15 秒，并相应调整运镜分段与动作密度。
- 若用户未指定时长，默认输出 **15 秒**。
- 仅当任务为生成**静态色卡参考图（Swatch Sheet）**时，不受此 15 秒限制。

## 各模块写作规范

### 1. 基础定调

控制在 1–2 句话，把时长、镜头运动、风格、质感一次性交代清楚。

示例：
> 15秒固定镜头，王家卫风格，浅景深，胶片质感。
> 15秒跨空间一镜叙事+两次硬切变装，王家卫风格，褪色油画暖调，胶片质感。
> 15秒连续运动长镜头，电影感超级视觉奇观，王家卫式褪色暖黄环境光，中国传统奇幻机甲风格。
> 8秒手持中景跟随镜头，Christopher Nolan + Hoyte van Hoytema 摄影风格，IMAX 65mm，shallow DoF，intimate close-up。

注意：所有示例时长均不超过 15 秒；若用户要求更长，必须压缩到 15 秒以内并重新分配时间轴。

### 2. 导演/摄影/技术规格与镜头角度

当用户提到具体导演、摄影指导、胶片格式或镜头参数时，必须单独成段，写清：
- **导演/摄影指导**：如 Christopher Nolan + Hoyte van Hoytema
- **胶片/数字格式**：如 IMAX 65mm、35mm Kodak Vision3、digital IMAX
- **摄影机运动**：handheld 微抖、稳定器平滑移动、固定机位、缓慢推/拉/摇/环绕
- **景深/光圈**：如 shallow depth of field（f/1.4 bokeh）、deep focus
- **景别**：如 medium shot（胸部到大腿中段）、close-up、extreme close-up
- **画幅比例**：如 anamorphic widescreen 16:9、IMAX 1.43:1（若适用）
- **焦距 / 焦段**：如 14mm 超广角、35mm 人文广角、50mm 标准、85mm 人像、135mm 长焦、300mm 超长焦

#### 焦距与镜头焦段选择

参考「焦距与视角」体系，生成提示词时必须根据画面需求精确指定焦距：

**A. 焦距与视角的关系**
- **焦距数值越小，视角越广**：能装下更多景物，主体相对较小，空间纵深感强，适合表现环境、宏大场景与临场感。
- **焦距数值越大，视角越窄**：远方的风景被拉得更近，主体被放大，空间压缩感强，背景被虚化或拉近，适合突出主体、特写与情绪。

常见焦距与视角对照：
| 焦距 | 视角（约） | 视觉效果 |
|---|---|---|
| 14mm | 114° | 超广角，强烈透视畸变，适合大场景、建筑、狭窄空间 |
| 24mm | 84° | 广角，环境感强，适合风景、街头、动态跟随 |
| 35mm | 63° | 人文广角，接近自然视角，适合叙事、中景、环境人像 |
| 50mm | 46° | 标准镜头，视角自然，适合人像、对话、日常场景 |
| 85mm | 28° | 中长焦，背景虚化柔和，适合人像特写、情绪镜头 |
| 135mm | 18° | 长焦，强烈空间压缩，适合远景抓拍、孤立主体 |
| 200mm+ | 12° 以下 | 超长焦，极致压缩，适合特写、剪影、远处细节 |

**B. 焦段分类与典型用途**
- **广角 10–35mm**：更适合风景、建筑、大场面、狭小空间、强烈透视感。
- **近标准镜头 35–85mm**：更适合人像、叙事、对话、日常感、自然透视。
- **长焦 85–135mm+**：更适合人文纪实、特写、情绪、压缩背景、突出孤立主体。

**C. 写入提示词的规范**
- 明确写出具体焦距数值：`shot on 35mm lens`、`85mm portrait lens`、`14mm ultra-wide angle`。
- 结合景别描述效果：`14mm 低角度仰拍突出建筑高耸`、`85mm 特写虚化背景`、`135mm 长焦压缩人群与主体距离`。
- 如需强调镜头语言，可标注 `wide-angle distortion`、`telephoto compression`、`bokeh`、`shallow depth of field`。

#### 镜头角度与构图系统

参考「AI 电影角度九大提示词」体系，生成提示词时必须精确描述以下要素：

**A. 高低视角**
- **平视 / Eye-level shot**：镜头与人视线齐平，最自然、最常用的基础镜头，适合叙事、对话，传递冷静、客观情绪。
- **高角度·俯拍 / High-angle shot**：镜头高于人物视线，从上方向下拍摄，模拟低头观察视角，传递孤独、渺小、无助、被审视的情绪，强化独行感与命运感。
- **低角度·仰拍 / Low-angle shot**：镜头低于人物视线，从下向上拍摄，模拟抬头仰望视角，常用于塑造英雄、神像或反派的威严，强化角色魅力，适合人物登场。

**B. 人物朝向**
- **正面 / Front shot**：镜头正对人物面部，180° 正对拍摄，完整呈现人物正面形象，展现情绪、神态，传递内心世界。
- **侧面 / Profile shot**：镜头与人物面部 90° 垂直，纯侧面拍摄，完整呈现人物单侧轮廓，捕捉沉思、观望瞬间，带有客观观察意味，传递冷峻、疏离情绪。
- **背面 / Back shot**：镜头位于人物正后方，180° 背对拍摄，完全隐藏人物面部，制造悬念和代入感，传递孤独、未知，适合开场、离别或探索场景。

**C. 特殊视角**
- **鸟瞰 / Bird's-eye view**：镜头从高空向下拍摄，模拟鸟类飞翔时的俯视视角，又称上帝视角，展现完整空间布局，交代环境全貌，打造史诗感、宿命感。
- **虫视 / Worm's-eye view**：镜头贴地面向上拍摄，模拟昆虫的仰视视角，又称蚂蚁视角，用夸张的透视与畸变带来强烈的视觉冲击和新奇感。
- **倾斜角度 / Dutch angle**：故意将镜头倾斜拍摄，让画面水平歪斜，营造失衡感，又称荷兰角，用视觉上不稳定传递紧张、不安、压抑、悬疑情绪，常见于动作片、惊悚片。

**D. 实战七要素分解**
当用户只提供一张参考图或简短需求时，按以下七要素快速拆解并写入提示词：
1. **景别**：全景 / 中景 / 特写 / 超近景
2. **构图**：居中构图 / 三分法 / 框架式构图 / 对称构图 / 留白构图
3. **角度**：平视 / 俯拍 / 仰拍 / 鸟瞰 / 虫视 / 荷兰角
4. **运镜**：固定镜头 / 推 / 拉 / 摇 / 移 / 环绕 / 手持微抖
5. **光影**：侧逆光 / 黄金时刻 / 顶光 / 底光 / 伦勃朗光 / 剪影光
6. **氛围**：暖色调 / 冷色调 / 复古美学 / 霓虹夜晚 / 低饱和 / 高对比
7. **主题**：西部游侠 / 赛博朋克 / 东方奇幻 /  noir / 公路片等

### 3. 场景空间关系

必须包含：
- **具体地点**（城市街道、室内空间、荒漠/古战场、海上、剧场舞台等）
- **时间/光线**（清晨、黄昏、霓虹夜晚、晨光斜射、褪色暖黄环境光、剧场红光等）
- **机位位置**（贴柜面上方、人行道边缘、斑马线旁、人物前方高空、观众席等）
- **镜头朝向**（朝向对面墙壁、朝向街道深处、朝向天空、朝向舞台深处等）
- **前景/中景/背景**分别是什么，哪些虚焦、哪些清晰
- **可见边界**（看不到地面/天花板/门，只有墙面等）
- **是否固定镜头**或**缓慢推/拉/摇/环绕/手持微抖**
- **人物与巨型物体/生物的尺度关系**（如机甲单手托人、人物站在巨人脚边等）

### 4. 色卡与色彩执行

当用户提供了色卡参考图时：
- 提取主色板 HEX 色值，按顺序列出
- 明确声明**色卡是整段画面的色彩锚点**：所有元素必须严格按 HEX 执行，环境光只能造成轻微偏移，不能改变色相
- 为每个画面元素严格分配颜色（上衣 #E8DFD0、长裙 #1A1A1A、激光红 #C42830 等）
- 说明环境光如何影响物体颜色（如"上衣被周围激光红光线染上微红光晕"）
- 标注**视觉异色点**：在统一色温中刻意出现的小面积对比色，写明其色相、位置、面积与叙事功能（如手机冷蓝光 #4A90E2 是朱砂红环境中唯一的冷色，成为视觉异色点）
- 说明哪些颜色必须严格锁定，哪些允许因光照产生轻微偏移

#### 色卡作为整段画面色板锚定

当用户要求"色卡作为整段画面色板锚定"时，按以下规范写入提示词：
- **前置声明**："色卡参考图 [N] 是本段画面的唯一色彩锚点，所有画面元素严格按以下 HEX 执行。"
- **主色板列表**：按画面出现频率或重要性列出全部 HEX 值（如 `#C42830` 激光红、`#1A1A1A` 深炭黑、`#E8DFD0` 米白、`#4A3828` 深棕、`#B59049` 金黄铜、`#9B1B1B` 朱砂红、`#0D0D0D` 深黑、`#4A90E2` 冷蓝等）。
- **元素到颜色的精确映射**：
  - 环境光/激光网络：`#C42830`
  - 未被照亮的阴影/剧场结构：`#1A1A1A`
  - 人物上衣：`#E8DFD0`，可被环境光染上微红光晕
  - 腰封/长裙：`#1A1A1A`，与阴影色相同但材质不同（布料反光 vs 墙体哑光）
  - 腰间布袋：`#4A3828`
  - 罗盘本体：`#B59049`，罗盘刻度：`#9B1B1B`
  - 智能手机本体：`#0D0D0D`（与长裙 `#1A1A1A` 形成微妙色差）
  - 屏幕冷光：`#4A90E2`（视觉异色点）
- **锁定规则**：明确"哪些颜色必须verbatim保持，哪些允许光照偏移"。
- **视觉异色点强调**：在统一色温中，唯一冷色点 #4A90E2 必须被强调为"the only cool color in the entire warm red environment"。

#### 视觉异色点强化写法

视觉异色点是在统一色温/色调中刻意安排的小面积对比色。写法要点：
- **色相**：写明具体 HEX（如 `#4A90E2` 冷蓝）。
- **位置**：出现在画面何处（手机屏幕上、人物手中、某一道缝隙光）。
- **面积**：强调"小面积"、"唯一"、"一抹"，避免大面积破坏色板。
- **叙事功能**：为什么这抹异色重要（如它是现代科技符号、是求救信号、是打破红色狂乱的冷静点）。
- **强制约束**：用英文强调其在整段画面中的唯一性，例如 `the only cool blue accent in the entire vermilion-red environment`, `no other cool colors present`。

示例：
> 丹眉右手从腰间深棕布袋掏出一部黑色智能手机 #0D0D0D，屏幕亮起冷蓝光 #4A90E2 拨号 UI。这抹冷蓝是整段朱砂红环境里的唯一冷色（the only cool blue accent in the entire warm red environment, no other cool colors present），在手机贴到右耳前持续可见。

#### 如何生成电影制作色卡参考图（Swatch Sheet）

当用户需要生成**用于电影调色的色卡参考图**时，提示词应包含以下要素：

1. **版式与布局**
   - 画布比例：landscape 16:9
   - 背景：纯白色，无纹理，无 Aging
   - 色块排列：单行水平均匀分布，数量明确（如 13 swatches）
   - 色块比例：约 2:3 竖向矩形
   - 边距与间距：左右等距，色块之间等距 gutter

2. **文字信息层级**
   - 顶部居中标题：项目名 + 集/段编号 + 主题 + 色板数量
   - 每个色块上方：简短描述性标签（说明该颜色在场景中的用途）
   - 每个色块下方：HEX 色值，使用等宽字体居中

3. **材质规则**
   - 色块：纯色平面，无渐变、无纹理、无阴影、硬边
   - 文字：无衬线字体，标签小字号，HEX 等宽小字号

4. **约束**
   - 严格保持 HEX 值，禁止色偏
   - 禁止插图、摄影内容、装饰元素、Logo、水印
   - 文字必须 verbatim，禁止字符替换

#### 罗盘类道具刻画

当画面核心道具为罗盘时，必须描述：
- **造型与材质**：圆形盘面，金黄铜本体 `#B59049`，边缘厚度与金属反光
- **刻度与指针**：朱砂红刻度 `#9B1B1B`，指针形状（勺形/箭形/菱形），指针是否颤动或稳定
- **朝向与位置**：罗盘正面朝镜头，被人物左手/右手紧紧握住，放在身前或腰间
- **与光线的互动**：罗盘的黄铜表面是否反射周围红光，刻度是否被红光打亮
- **叙事功能**：罗盘是指引方向、探测能量、还是触发事件的钥匙

示例：
> 丹眉左手单手拿罗盘 #B59049（罗盘朱砂红刻度 #9B1B1B + 金黄铜本体）放在身前，罗盘正面朝镜头，她紧紧握住罗盘。罗盘黄铜边缘反射周围激光红 #C42830 的微光，刻度在红光中清晰可辨。

#### 手机类道具刻画

当画面核心道具为智能手机时，必须描述：
- **外观颜色与材质**：手机本体深黑 `#0D0D0D`，与服装/背景形成微妙色差（如与深炭黑长裙 `#1A1A1A` 形成色差）
- **屏幕状态**：屏幕亮起时的具体 UI（拨号界面、来电显示、短信界面等），屏幕冷光 `#4A90E2` 作为视觉异色点
- **握持与动作**：哪只手掏出手机、手指如何在屏幕上点击、拇指/食指的动作
- **运动轨迹**：从腰间布袋掏出 → 举到胸前 → 贴到耳边的完整过程
- **声音同步**：拨号音、接通"嘟"声、按键音与画面动作精确对齐

示例：
> 丹眉右手稳稳伸进腰间深棕布袋 #4A3828，从布袋掏出一部黑色智能手机 #0D0D0D（手机本体深黑，与深炭黑 #1A1A1A 长裙形成微妙的色差）。她在手机屏幕上点几下，屏幕亮起冷蓝光 #4A90E2 拨号 UI。伴随手机拨号音和接通"嘟"的一声音效。

**声音设计参考**：当用户提到具体作曲家或风格时，明确写出：

- **写法**：`cool blue electronic dial tone beep cuts through the low-frequency red environment`, `high-frequency shimmer accompanying the only cool light source`。

### 16. 高阶电影技巧（参考 Nolan / IMAX / 东方奇幻机甲案例）

当用户给出高复杂度、强视觉冲击力的场景描述时，按以下技巧拆解并写入提示词：

#### A. 极端光影与选择性照明
- 明确光源位置与照射范围，未被照射区域沉入纯黑（如 `#0E0E0E`）。
- 用 rim light 勾勒人物边缘：脸、头发、肩膀边缘被红光 #C42830 打亮，其余为剪影。
- 写清禁止项：`NO stage spotlights`, `NO chandeliers`, `NO ambient lighting`。
- 示例：「剧场深陷纯黑暗——墙体、拱顶、地板、座椅只在被红光打到的位置可见，其他位置沉入纯黑暗。」

#### B. 方向性能量 / 粒子流动

- 光线、雾气、碎屑必须沿明确方向运动，并写入禁止反向的约束。
- 示例：「激光红 #C42830 辐射线从远处对面墙的哥特拱形虚空门内涌出，穿过观众席上方，向丹眉延伸（OUT FROM door TOWARD Danmei, NEVER reverse）。」
- 雾气比喻：「vermilion red mist flowing along rays like blood through arteries」。

#### B+. 高速光线 / 粒子网络

当用户描述"密集光线形成网络"、"红光像高速电流一样流动"、"粒子沿光线高速冲"时，按以下规范写入：
- **网络结构**：光线以中心向外辐射，形成密集交织的网络（dense interweaving red laser network），覆盖中景/背景空间。
- **粒子运动**：每条光线上都有亮点/粒子以肉眼可见的速度从中心向外冲（red light particles streaming rapidly along each line at high velocity from center outward）。
- **流动比喻**：使用比喻强化流动感，如 `like luminous fluid surging through veins`, `like high-voltage current racing through optical arteries`。
- **方向锁定**：明确写入 `from center outward`, `NEVER reverse`, `NEVER flow inward`，防止粒子反向运动。
- **速度感**：用 `high velocity`, `rapidly`, `visible to naked eye`, `multiple pulses per second` 等词强调速度。
- **与景深结合**：背景光线网络因 shallow DoF 而虚化，但流动感仍然清晰可辨。

示例：
> 背景里依稀可见激光红 #C42830 辐射光线密集穿过空间形成红光网络，这些红光线像高速电流一样在自身方向上快速流动（red light particles streaming rapidly along each line at high velocity from center outward, like luminous fluid surging through veins）。每条红光线上都有亮点在以肉眼可见的速度从中心向外冲，方向始终从中心向外，绝不反向（NEVER reverse）。

#### C. 环境力的视觉证据链

- 把看不见的风压/能量场转化为可见细节：
  - 人物头发完全水平向后飞舞，发梢剧烈拍打
  - 近处座椅前后摇晃倾斜
  - 空气中碎纸、灰尘、碎屑高速飞舞
  - 衣料 flapping，布料鼓动
- **冲击波纹**：能量爆发时可见强烈密集的同心圆冲击波纹从人物位置向外扩散（intense visible concentric shockwave ripples emanating outward from character's position with high frequency），每秒多次扩散。
- **尘埃轨迹**：空气中尘埃粒子被强风高速推动，画面里能清晰看到尘埃被吹动的轨迹（visible dust particle trails streaking through the air）。
- 写明粒子来源方向与运动方向：「碎纸碎屑从远处对面墙方向飞向画面前方」。

#### D. 复合镜头运动与同步变换
- **Orbit + Dutch angle 同步**：镜头环绕人物时，荷兰角同步倾斜；运动停止瞬间角度同步恢复。
  - 示例：「counter-clockwise orbit 180-degree semicircle around Danmei from front-left to directly behind, dutch angle 12 degrees to the left during orbit, tilt to 0 at exact moment orbit stops」。
- **固定机位 + focus pull**：镜头完全静止，焦点从前景人物推到远景门/物体。
  - 示例：「镜头保持 orbit 结束的位置和角度，绝对不 zoom out、不远离丹眉；focus pull 从前景丹眉推到远景门，丹眉始终虚化」。
- **前景框架构图**：人物始终占画面底部约四分之一，作为前景虚化框架。
  - 示例：「丹眉后脑勺和肩膀始终占画面底部前景约四分之一，始终前景虚化」。

#### E. 远景元素逐步扩大
- 门/洞/巨型物体轮廓在画面中逐帧扩大，增强压迫感。
- 示例：「巨大哥特拱形虚空门起初是墙上微弱发光轮廓，轮廓在画面里持续扩大（door outline expanding frame by frame, occupying more and more wall area）」。

#### F. 巨型物体逼近与黑屏收束
- 标准动作链：
  1. 从远景门/洞中出现
  2. 向镜头方向移动并逐帧变大
  3. 越过前景人物所在深度
  4. 临近结尾出现 heavy motion blur
  5. 完全覆盖画面
  6. 在五指合拢 / 抓取瞬间 abrupt cut to pure black
- 示例：「关羽机甲右手从门内伸出，五指张开自然伸展，逐渐变大，穿过观众席上方，越过丹眉所在前景深度，继续在画面里放大；临近结尾 motion blur 出现，高速放大，张开手掌完全覆盖画面，在五指合拢抓住丹眉的瞬间全黑。」

#### G. 声音设计的阶段化推进
- 把 15 秒按情绪曲线分层设计声音：
  1. **铺垫阶段**：低频 wind tunnel roaring + 发丝拍打 + 布料 flapping + 平稳呼吸 + air pressure wobble
  2. **揭示阶段**：低频 drone 升高 + crackling energy crackle + ancient resonance hum + fluid surging energy sound
  3. **高潮阶段**：metallic crash impact + ancient mechanical joints groaning + Hans Zimmer BRAAAM crescendo
  4. **收束阶段**：巨大低频 boom + abrupt cut to silence
- 必须区分 sound design 与 BGM：用户要求无 BGM 时，只写环境音与动作音效。

#### H. 否定性精确约束（NOT / NEVER / REMAIN / NO）
- 对容易出错的关键元素，用否定句和强制保持句强化：
  - `NEVER reverse`
  - `NOT vacant`
  - `NO stage spotlights`
  - `REMAIN at lower-quarter foreground, REMAIN out of focus`
  - `NOT fist, NOT grip`
  - `abrupt cut to pure black, NO fade out`

#### I. 色卡锚定与视觉异色点强化

- **色卡锚定前置声明**：在【色卡与色彩执行】模块开头必须写："色卡参考图 [N] 是本段画面的唯一色彩锚点，所有元素严格按以下 HEX 执行。"
- **元素到 HEX 的精确映射**：每个可见元素都必须有颜色归属，不允许出现未分配颜色的物体。
- **视觉异色点的四要素**：色相（HEX）、位置、面积、叙事功能缺一不可。
- **强制唯一性约束**：用英文强调 `the only [color] accent in the entire [dominant color] environment`, `no other [cool/warm] colors present`。
- **反例排除**：在视觉异色点出现时，周围区域不得出现其他同色相色块，防止异色点被稀释。

#### J. 道具色彩微差控制

- 当道具与服装/背景处于同一深色系时，必须写出具体 HEX 色差，不能只说"黑色"或"深色"。
- 示例：手机 `#0D0D0D` vs 长裙 `#1A1A1A`；腰带 `#4A3828` vs 头发 `#0D0D0D`。
- 通过材质差异强化可辨识性：哑光布料 vs 光滑塑料/金属反光。
- 在提示词中明确 "subtle but visible color difference"，帮助模型区分相邻深色物体。

#### K. 冲击波纹与尘埃轨迹

- **冲击波纹**：能量/风压从人物位置向外扩散，形成强烈密集的同心圆冲击波纹（concentric shockwave ripples），每秒多次扩散，波纹可见且频率高。
- **尘埃轨迹**：空气中尘埃粒子被强风高速推动，形成清晰可见的运动轨迹（visible dust particle trails streaking through the air）。
- **方向一致性**：冲击波纹和尘埃轨迹的方向必须与风压/能量方向一致，写入 `emanating outward from [character/object]`, `NEVER inward`。
- **与景深结合**：背景尘埃轨迹因 shallow DoF 虚化，但运动方向和轨迹仍然清晰。

#### L. 声音对比设计

- 在统一低频/暖调/压迫性声场中，刻意安排瞬间出现的异色声音，形成听觉上的视觉同步对比。
- **异色声音类型**：
  - 电子拨号音、手机按键音、屏幕亮起时的电子提示音
  - 冷色光源伴随的高频细微嗡鸣
  - 现代设备特有的清脆机械声
- **对比维度**：低频 vs 高频、暖调 vs 冷调、自然声 vs 电子声、连续 drone vs 瞬间 beep。
- **写法示例**：
  > 手机接通瞬间，冷蓝屏幕亮起伴随手机的电子拨号音（cool blue electronic dial tone beep），与周围低频压制的红光环境形成声音对比。
- **必须区分 sound design 与 BGM**：声音对比是 sound design 的一部分，不是背景音乐。

#### M. 手持微抖与缓慢跟随的精确写法

- **抖动程度**：`handheld micro-shake`（轻微）、`handheld nervous tremor`（紧张）、`shoulder-mounted documentary shake`（纪实）。
- **跟随方向**：`slowly pan up`（缓慢上摇）、`slight push in`（微微推进）、`gentle drift to the right`（轻微右移）。
- **动作触发**：手持运动必须对应画面中的人物动作（如跟随人物举手机的动作上摇）。
- **停止条件**：写明镜头何时停止运动（如"手机贴到右耳后镜头停止上摇"）。
- **与 shallow DoF 结合**：手持微抖 + f/1.4 bokeh + intimate framing 可强化临场感。

#### N. 单镜头内完整动作链的写法

当用户要求"单镜头"完成一个复杂动作时，按以下顺序拆解：
1. **初始姿态**：人物起始动作、道具位置、视线方向。
2. **手部动作细化**：哪只手、伸向哪里、如何握住/取出道具。
3. **道具出现与互动**：道具从何处出现、如何被操作、屏幕/指针/刻度的变化。
4. **身体动作联动**：头部、肩膀、头发、衣料如何随主体动作变化。
5. **镜头运动同步**：手持微抖、pan、tilt、push in 如何跟随动作。
6. **动作终点**：动作完成时的最终姿态、道具最终位置、镜头停止状态。
7. **声音同步**：每个关键动作节点对应的具体音效。

15秒跨空间一镜叙事+两次硬切变装，王家卫风格，褪色油画暖调，胶片质感。

【场景空间关系】

当用户提供色卡、剧场场景、人物和罗盘，并要求 Nolan/IMAX/handheld 风格时，输出应严格按色卡分配颜色、将色卡声明为整段画面锚点、标注视觉异色点（如手机冷蓝屏）、写出高速光线网络中粒子从中心向外的流动、冲击波纹与尘埃轨迹、道具色彩微差、手机拨号音等具体音效。

## 执行流程

1. 先读取用户提供的所有参考图片，理解场景、人物、光线、构图、尺度关系、色卡
2. 询问或推断：时长、地点、核心情绪、初始景别、**镜头角度（平视/俯拍/仰拍/鸟瞰/虫视/荷兰角）、人物朝向（正面/侧面/背面）、焦距/焦段（14mm/35mm/50mm/85mm/135mm/200mm+）、构图方式、光影、氛围、主题**、是否有变装/转场/巨型物体 reveal / 一镜到底 / orbit 环绕 / 荷兰角同步变换 / focus pull / 黑屏收束 / **色卡锚定 / 视觉异色点 / 高速光线网络 / 冲击波纹尘埃轨迹 / 道具色彩微差 / 声音对比设计** / 台词 / 平台参数 / **是否需要生成色卡参考图（Swatch Sheet）** 需求
3. 判断任务类型：
   - 若用户要生成**色卡参考图**：按 Swatch Sheet 规范输出（版式、HEX、标签、约束）
   - 若用户要生成**视频提示词**：判断风格方向（王家卫真人胶片 / Nolan IMAX / 厚涂 2D 概念艺术 / 中国传统奇幻机甲），按视频模板输出
4. 按上方模板生成 9–12 个模块的提示词
5. 自我检查：
   - **总时长是否 ≤15 秒**（视频提示词强制上限）
   - 时间轴是否连续无跳跃
   - **镜头角度、人物朝向、构图方式是否明确写入提示词**
   - **焦距/焦段是否明确写入提示词，并与景别、空间关系一致**
   - 人物一致性约束是否写明（脸部/发型/身高比例不变）
   - 色卡 HEX 值是否已分配到具体元素
   - 视觉异色点是否被强调
   - 巨型物体与人物的比例关系是否一致
   - **极端光影场景是否明确光源位置、照射范围、禁止出现的环境光**
   - **方向性能量/粒子是否有明确运动方向，是否写入 NEVER reverse 等反向约束**
   - **环境力（风压/能量场）是否有可见证据链（头发、碎屑、座椅、衣料等）**
   - **复合镜头运动（orbit + dutch angle / focus pull + 固定机位）的同步关系是否写清**
   - **远景门/巨型物体是否在画面中持续扩大**
   - **巨型物体逼近+黑屏收束的动作链是否完整（出现→变大→越过前景→motion blur→覆盖画面→抓取→abrupt cut to black）**
   - **声音设计是否按阶段推进（wind tunnel → drone → energy crackle → BRAAAM → abrupt silence）**
   - **声音对比设计是否写入**：视觉异色点出现时是否有同步的异色声音（电子拨号音/屏幕音）
   - **色卡锚定声明是否前置**：是否写明"色卡参考图 [N] 是本段唯一色彩锚点"
   - **视觉异色点四要素是否完整**：色相（HEX）、位置、面积、叙事功能
   - **高速光线/粒子网络是否完整**：密集网络 + 粒子沿光线高速流动 + NEVER reverse
   - **冲击波纹与尘埃轨迹是否写入**：同心圆冲击波纹 + visible dust particle trails
   - **道具色彩微差是否明确**：核心道具与相邻深色元素是否有可辨识 HEX 色差
   - **罗盘/手机类道具细节是否完整**：刻度/指针/屏幕 UI/冷光/拨号音
   - 转场逻辑是否物理上可行
   - 道具运动轨迹是否清晰（出现→互动→成为镜头锚点→最终状态）
   - 手持/稳定器运动描述是否具体（抖动程度、跟随方向、停止条件）
   - 音效是否与画面动作一一对应
   - 声音曲线是否有从静到爆的层次感（如适用）
   - 台词音色、语气、口型要求是否写明
   - 视觉风格关键词是否足够具体，负面排除词是否完整
   - 平台输出参数和否定约束是否列出
6. 输出完整提示词，并简要说明可变参数
